### 3.6 ⭐ 视频实测基准（2026-09-20，真机跑通）

用应用自带的 `U视频-MINIMAX-H3/U03-minimax_h3_light2v-文生视频加速版.json` 实跑一条（提词：黄昏雨巷里漂着纸船、灯笼暖光、镜头缓推）：

| 指标 | 实测值 |
|---|---|
| 模型 | `minimax/minimax_h3_fl2va_pruned_int8_convrot.safetensors` + 加速 LoRA `minimax_h3_fl2v_turbo_8step_v1.0`（8 步 turbo） |
| 文本编码器 / VAE | `qwen3vl_32b_minimax_h3_nvfp4_awq` ｜ 视频 VAE `minimax_h3_video_vae_fp16` + **音频 VAE `minimax_h3_audio_vae_fp32`** |
| 输出 | **864×480 ｜ 107 帧 ｜ 4.46 秒 @24fps ｜ H.264 + AAC 音轨 ｜ 483 KB** |
| **耗时** | **93.5 秒**（含首次权重加载；采样 10 步 + H3SigmaRefiner 补 2 步 0.65→0） |
| 画质 | 可用：运镜（缓推）正确、画面干净、提词吻合、**自带音轨（音画同步生成）** |
| 质量设定 | 走模板内置的 `MiniMaxLowVRAMAttention`(head_chunks=4) + `MiniMaxChunkFeedForward`(chunks=4, seq>4096) + `ModelPreviewOverrideKJ` + 两处 `VRAMCleanup`（显存优化链路，83G 卡上很稳） |

**跑法（关键）**：应用自带模板是 **UI 格式**（`nodes`+`links`+`widgets_values_named`），**不能直接 POST /prompt**。转换器已存为技能脚本 `autodl/scripts/run_wf_api.py`，四要点：① `widgets_values_named` 当输入名→值（只取 `/object_info` 声明的名字，嵌套点号键丢掉）；② link 优先于 widget；③ `mode==2` 跳过、**`mode==4`（bypass）要透传**（模板里 `RTXVideoSuperResolution` 默认就是 bypass）；④ UI 专用节点（`Label (rgthree)` 等）自动跳过。

**结论**：这台可以承接内容工厂**阶段③ 视频制作**的最小闭环（文生视频/图生视频/首尾帧/多图参考），且有数字人、动作迁移、声音克隆等模板可继续标定。

## 五、已知缺口与注意事项

1. **6000D 不能跑抠图**（缺 RMBG 节点）——多实例调度若要严格按能力分流，需要「按任务类型过滤可用实例」；当前实现只做「开机失败换下一台」，**不会**因缺节点而换机（会在提交工作流时 400 失败）。
2. **6000D 磁盘仅剩 15G**：视频产物（几秒 720p 就要几十上百 MB，长视频更大）容易写满 → 跑视频前先清盘 / 把产物直接拉回媒体站。
3. **模型名按实例适配是必需的**：同名模型在两台的目录前缀不同（`Wuli-…` vs `Qwen/Wuli-…`），代码在提交前用该实例 `/object_info` 自动解析（日志会打印「ⓘ 模型名适配：A → B」）。
4. **域名与 SSH 端口都是移动靶**：换区/重建后 ComfyUI 域名变（代码用 `/snapshot` 的 `service_6006_domain` 实时取，自愈）；SSH 端口同理，且应用镜像的 sshd 启动较慢（第一次探可能 CLOSED）。
5. **不要缓存 ComfyUI 地址**：以实时域名为准，settings 里配的地址只作首选（探不通自动回落）。
6. 自动关机开关（`comfy_auto_shutdown`）会关掉**本次用的那台**；要长期常开某台（例如跑视频），把它从池里去掉或关掉自动关机。
